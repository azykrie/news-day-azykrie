One 1024×1024 poster summing up Sunday 22 November 2026: COP31's collapse in Antalya, the strikes in Ukraine and Gaza, record Hormuz attacks, the Benghazi warship, Mexico's cartel arrest, and the China–US FCC row.

`entry.png` is the judged file (a JPEG encoded under that name, within the 1 MiB / 1024 px caps). `poster.html` is the source the agent rendered it from; `NEWS.md` records the reporting behind each line. `main.ts` checks the file and copies it to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
